# HandHarmony

### Overview
HandHarmony is a simple app designed for people to play and harmonize melodies. A user can sing/whistle/play a base note and finger the melody in that note's scale.

### Languages & Tools
<ul>
  <li>ChucK</li>
  <li>ChAI</li>
  <li>Python</li>
  <li>MediaPipe</li>
</ul>
